# LoRA レポート比較ビューア

`tools/lora_comparison.html` をブラウザで開くと、生成済みの診断JSONを比較できます。HTMLを任意のフォルダへ手動コピーして使うこともできます。Python、サーバー、ネット接続は不要です。

学習batや `make_lora_diagnostic_report.py` の使い方は変わりません。新しいランが増えても、ビューアを作り直す必要はありません。

## 基本操作

1. ビューアを開き、`*_diagnostic.json` を複数選択するか、画面へドロップします。
2. 「比較するラン」のチェックで、同時に表示するランを選びます（最大4ラン）。追加で読み込んだランは候補として保持します。
3. 左側の「グラフを選ぶ」で、Loss、DQ、Rank、Group Loss、情報密度推移などを選びます。
4. 「表示系列」を開いて、比較したい線を選びます。
5. 必要なら「比較をHTMLに保存」で、その状態を保存します。

入力はHTMLではなく、単独レポートと同時に作られたJSONです。JSONとビューアが同じフォルダにある必要はありません。1ファイルの上限は128 MiBです。

## 表示の切り替え

| 操作 | 内容 |
|---|---|
| 重ねる | 同じグラフ上で複数ランを表示。色はラン、線種は系列 |
| 並べる | ランごとのグラフを共通の縦軸目盛りで表示 |
| 基準との差 | 対象の値から基準ランの同名系列の値を引いて表示 |
| 元の横軸 | JSONに保存されたTrainStepやEpochを使用 |
| 記録範囲の進捗 % | 各グラフの最初〜最後の有効記録を0〜100%に換算 |
| 範囲 | 全記録、共通範囲、共通範囲の終盤20%、数値指定 |

初期表示のLossは移動平均を選択しています。raw Lossも「表示系列」から選べます。系列が多いグラフは初期状態で先頭4系列を選ぶため、必要に応じて変更してください。

通常の線グラフ比較では、元JSONの固定範囲、範囲に含める基準値、目盛り間隔・整数表示・小数桁数を反映します。ラン間で範囲が異なる場合は両方を含む共通範囲を使い、目盛り間隔が異なる場合は自動調整します。目盛りが多い場合は指定間隔の整数倍に広げます。差分表示には元の軸指定を適用せず、差に合わせて自動調整します。

ヒートマップは、各ランの最終記録を共通の行列・色目盛りで並べます。最終epoch・stepが異なる場合は、各パネルの表示で確認できます。

カーソルを合わせると近い実記録の位置と値を表示します。クリック／タップで固定し、再クリックまたはEscで解除できます。

## 値の扱い

- データがないグラフ・系列は追加せず、一部のランだけ未収録ならその旨を表示します。値が0の系列は表示します。
- 欠損値を0に置き換えず、線を途切れさせます。
- 差分は同名の系列を比較します。基準側だけが欠測している場合も、その区間で差分の線を切ります。対象側の記録点を増やすことはなく、描画用の切れ目は記録数・平均等の集計に影響しません。同じ位置に基準の記録がない場合、連続量は線形補間、Bits等の離散量は直前値を使います。基準の範囲外や欠損をまたぐ補間は行いません。
- 「表示範囲の記録値」の平均は、表示系列に含まれる有効な記録値の単純平均です。移動平均の系列を選べばその系列の平均になり、raw Lossの平均や時間平均とは異なります。差分表示中は差分値を集計します。
- 密な線は描画時のみ点数を減らします。区間表とツールチップには元の記録を使います。
- 記録範囲の進捗100%は、選んだグラフの記録末尾です。学習の完走を意味しません。
- 横軸やMetric・Scopeの記録が異なる場合は、無条件に重ねず並列表示します。詳細は「元レポートの補足」で確認できます。
- 元JSONにある移動平均や情報密度の値を使います。平滑化幅や正規化条件、学習条件の違いを補正する機能はありません。

既存JSONにない平均化の採用履歴、完全な実行設定、元ログの全モジュール時系列、画像評価などは、初期版では追加解析しません。

## 保存と更新

保存した比較HTMLには、読み込んだランのデータと、基準・系列・範囲などの表示状態が含まれます。元JSONのない別フォルダでも開けます。再表示後に新しいJSONを追加し、再保存することもできます。

ファイルはブラウザの保存先へ保存されます。元JSONや単独レポートは変更しません。保存しないままページを閉じると、読み込んだ状態は失われます。

ビューアの更新は、新しい `lora_comparison.html` をコピーし直してください。保存済み比較HTMLは保存当時のビューアを含むため、自動では更新されません。

## 開発時の検証

`tests/test_lora_comparison.cjs` はNode.jsとPlaywrightを使うブラウザ統合テストです。これらは開発時のみ必要で、ビューアの利用者には不要です。

```text
node tests/test_lora_comparison.cjs
```

必要に応じて、`LORA_VIEWER_PLAYWRIGHT_MODULE`（Playwrightモジュールのパス）、`LORA_VIEWER_BROWSER`（Chromium系ブラウザの実行ファイル）、`LORA_VIEWER_ARTIFACTS`（検証結果の保存先）を環境変数で指定できます。

旧グラフID、欠損とゼロ、基準との差、共通目盛り、区間、ツールチップ、ヒートマップ、重複・破損JSON、保存・再表示、画面幅・テーマ、オフライン動作を検証します。


## 学習設定の比較（0.2.0）

新しい診断JSONに含まれる学習設定を、ラン一覧の下に折りたたんで表示します。既定は差分・一部未記録の項目のみで、すべての設定にも切り替えられます。旧JSONのグラフ表示はそのまま使えますが、設定を追加するには診断JSONを再生成してください。

設定記録ファイル由来／メタデータ由来を表示し、未記録をOFFや0として比較しません。optimizer作成時のLRと学習開始時のLRは、引数のLRと別に表示します。取得元の詳細と記録範囲は [学習設定の仕様](lora-training-settings-spec-ja.md) を参照してください。
